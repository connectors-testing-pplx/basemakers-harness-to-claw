# Every Harness Will Become A Claw — First-Principles Analysis

A **Basemakers** first-principles analysis of Sam Bhagwat's talk on the AI Engineer channel.

## About

This project deconstructs Sam Bhagwat's thesis — **"Every harness will expand until it becomes a claw"** (Steinberger's Law) — from first principles, stripping away analogy and rebuilding the AI agent stack from irreducible truths: LLM → Agent → Harness → Claw.

## What's Inside

A single self-contained Apple-style HTML document (`index.html`) with five custom inline-SVG data visualizations:

1. **The Ascent** — the agentic spectrum as an ascending path
2. **Capability Architecture** — the layered superset stack
3. **Steinberger's Law** — the three expansion force vectors (technological, economic, psychological)
4. **Harness vs Claw** — a six-row capability matrix
5. **The Shakeout Curve** — the consolidation trajectory forecast
